# Jacques Schneider WWI archive

An interactive family-history archive combining:

- three versions of Jacques Schneider's journey map;
- synchronized oral-history audio and chronological transcript;
- line-level transcript correction comments with JSON export/import;
- German casualty-list, regimental-history, immigration, census, and geographic evidence.

## Website

The GitHub Pages site opens at:

<https://cbevacquatech.github.io/grandpere-ww1-journey/>

The original MP3 recordings are preserved without modification. The transcript player seeks into those files and creates a virtual chronological playlist in the browser.

## Main pages

- `maps/narrator_journey_interactive.html` — journey map and documentary evidence
- `maps/chronological_transcript_player.html` — chronological audio and transcript reader
- `transcripts/chronological_edited_transcript.md` — edited source transcript

Transcript comments are stored in each reader's browser. They can be exchanged using the player's JSON export and import controls.
